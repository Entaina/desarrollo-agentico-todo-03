# Conoce las herramientas del agente

Enumera todas las herramientas de desarrollo integradas que tienes disponibles, excluyendo servidores MCP.

Para cada herramienta muestra:

- su nombre;
- una firma breve con sintaxis de función TypeScript;
- qué permite observar o modificar.

No ejecutes ninguna herramienta ni cambies el proyecto. El objetivo es que la persona comprenda qué puede hacer el agente en esta sesión.
